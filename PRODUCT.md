# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Lean static HTML and CSS, generated from Markdown by a small Node build. No application framework or backend. Hosting remains portable; Sevalla Static Sites is the proposed destination, not yet deployed.

## Users and purpose

Yoren uses this living document to return quickly to individual instructions. Other readers can understand how Yoren wants to work. It is not a blog, résumé, portfolio, or agency website.

## Content and constraints

README.md is the sole source of public document content. Generate the page, navigation, and downloadable Markdown from it. Do not invent biography, accomplishments, revision dates, or personal annotations.

The repository is public. Only approved content and implementation belong here. Private source material, working notes, and review artifacts must not be published.

## Confirmed interaction

Persistent desktop rule index; a single mobile rule menu. All instructions stay readable in one continuous document. Rules have shareable URL fragments. Selecting a rule closes the mobile menu.

## Principles

- Optimize for returning to a particular rule.
- Keep content separate from presentation, without duplicated text.
- Make navigation useful without turning the document into an application.
- Preserve a usable reading experience without JavaScript.
